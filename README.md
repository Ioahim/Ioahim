## Featured projects

### [Cheater Watcher CS2](https://github.com/Ioahim/Cheater-watcher-cs2)
Full-stack app that analyzes Counter-Strike 2 demos, scores and flags suspected cheaters.
**Next.js + TypeScript + Tailwind** frontend, **ASP.NET Core** API, **PostgreSQL** with **EF Core**, all orchestrated with **Docker Compose**.

### ReactFarm - animal reactivity assessment
Low-cost device (**ESP32 + MPU6050**) with an **Android** app over Bluetooth to objectively measure cattle reactivity.
Field-validated on **257 animals** (Spearman ρ = 0.965), technology readiness level **TRL 6**.
[Embrapa Technical Circular 91](https://www.infoteca.cnptia.embrapa.br/infoteca/handle/doc/1187582)

### Carcass segmentation in ultrasound images (MSc research, in progress)
Semantic segmentation of beef cattle carcass structures in ultrasound images, comparing **U-Net, UNet++, DeepLab v3+ and SegFormer**.
Preliminary UNet++ results: **Dice 0.953** and **IoU 0.910** on the ribeye area.

### [Fotoxopi](https://github.com/Ioahim/Fotoxopi)
Desktop image editor built from scratch in **WPF (C#/.NET)** with intensity and geometric transformations, for an Image Processing course.
